# LYMPHODOOM

Doom (1993) inside the human body. You are a killer T cell; three levels take you from a
lymph node through the bloodstream into a tumor. Runs in the browser:
https://kostachernyshov.com/lymphodoom/ · https://kostachernyshov.ru/lymphodoom/

## What is here

| Path | What |
| --- | --- |
| `art/` | Sprites, weapons, textures, HUD and screens, drawn in code with the Cancer Wars palette |
| `vendor/pixel_kit/` | The subset of Cancer Wars `pixel_kit` the art is built on (palette, primitives, cast) |
| `tools/build.py` | Builds `lymphodoom.wad` (the IWAD) and a palette-matched `prboomx.wad` |
| `tools/maps.py`, `tools/mapgen.py` | The three levels (polygon sectors, organic rooms and tubes; nodes by zdbsp) |
| `tools/sfx.py`, `tools/music.py` | Procedural sound effects and original MIDI music |
| `tools/dehacked.py` | DEHACKED/BEX strings and stats, UMAPINFO for the 3-level episode |
| `engine/` | Patch for [Dwasm](https://github.com/GMH-Code/Dwasm) (PrBoomX/PrBoom+ in WebAssembly), default config, build script |
| `web/` | The game page (EN `index.html`, RU `ru.html`, generated by `tools/page.py`) and `.htaccess` |
| `tools/playtest.py` | Headless play-test with the native engine (Xvfb + xdotool), screenshots |
| `docs/bible-addendum.md` | Where the game departs from the Cancer Wars bible |

## Build

Needs Python 3 (pillow, numpy, shapely), zdbsp, git, cmake, a C compiler with SDL2/SDL2_mixer
dev packages (for the native step), Emscripten, and `freedoom1.wad` from
https://github.com/freedoom/freedoom/releases (only GENMIDI/DMXGUS and a few UI lumps are taken).

    sh engine/build.sh /path/to/freedoom1.wad

The result is `web/game/index.{js,wasm,data}` plus `.gz` copies. Copy `web/` (without
`page.template.html`) to the site as `public_html/lymphodoom/`.

Engine patches (`engine/lymphodoom.patch`, against Dwasm `ddf0347`): the IWAD is recognised as a
registered Doom 1 episode; three skill levels; the body-map intermission (spots, no animations,
a plain stats background); menus on the title screen get a clean background; UMAPINFO episodes
are not trimmed; an `endpic` without `intertext` goes straight to the picture; cheat handlers share
one signature so the build runs without `EMULATE_FUNCTION_POINTER_CASTS`.

`LYMPHO_TEST_BOSS=1 python3 tools/build.py ...` makes a test build where the boss dies at spawn
next to the player (checks the boss-death exit and the finale).
