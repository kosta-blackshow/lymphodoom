# LYMPHODOOM: additions to the Cancer Wars bible

The game uses the Cancer Wars character bible (palette PICO-8, heroes white with a coloured rim,
villains plum with a red rim). These are the places where the game adds to it or departs from it.

- **Scale.** Bible sprites are 14–26 px; in the game one bible pixel is 3 Doom units for world
  sprites and 4 screen pixels (the bible's own video scale) for the first-person weapons.
- **Palette.** Sprites use only the 16 PICO-8 colours. The 256-colour Doom palette adds 15 fog
  shades for each colour (towards a dark navy) so sector lighting fades smoothly; textures use them.
- **Explosions.** In the bible cells die by apoptosis. In the game every enemy bursts: white-hot
  flash, a cloud in its own colours, chunks, a puddle. This is a game convention, not biology.
- **Microbes** (not in the bible): viruses LAV with pink rim and spikes, bacteria ORANGE/BROWN rods
  with flagella, parasite PEACH/BROWN fluke, fungal spore DGREEN/LGREY, phage LGREY/LAV. All have
  villain faces (angry brows, red eyes). Red stays reserved for tumour cells.
- **Red blood cells** are drawn PINK, because red is reserved for villains.
- **Keys** are MHC-I badges: white, yellow (self peptide) and orange (neoantigen).
- **Enemy roles** follow Doom 1 monsters: VIRUS = zombieman, BACTERIUM = shotgun guy,
  TUMOR CELL = imp, PARASITE = demon, TUMOR NO MHC-I = spectre (drawn with the fuzz effect:
  without MHC-I a T cell can hardly see it), PHAGE = lost soul, FUNGAL SPORE = cacodemon,
  TUMOR MASS = baron (boss of E1M3; its death ends the game).
- **Weapons**: synapse punch, granule gun, cytokine burst, granzyme stream, antibody bomb,
  interferon, CAR-T boost. Pickups: glucose (health), membrane (armour), IL-2 surge
  (soulsphere), mucus coat (radiation suit), dendritic scout (computer map).
